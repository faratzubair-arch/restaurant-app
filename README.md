# Restaurant App MVP - Complete Assignment Submission

Welcome to the official repository for our **Restaurant Application MVP** project. This project is a comprehensive cross-platform mobile application developed using React Native and Expo, designed to streamline restaurant management, table reservations, and food ordering.

## ✨ Key Features & Functionalities
1. **User Authentication & Authorization:** Secure login and registration screens supporting role-based access for customers and managers.
2. **Interactive Menu & Ordering:** Browse food items, view categories, add items to the cart, and manage order summaries seamlessly.
3. **Table Reservations:** Book restaurant tables in advance with custom date and time slots.
4. **Manager Dashboard:** Administrative interface for monitoring orders, managing menu items, and overseeing daily restaurant operations.
5. **Theme Support:** Modern dark/light theme switching using custom hooks and context providers.
